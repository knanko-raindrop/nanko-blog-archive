powerpointで300dpiや600dpiのtiff画像を作る

2020年07月28日 09:18:00便利ツール・手法

記事は投稿当時の情報を保存したものです。現在の情報とは異なる可能性があります。

Powerpointを駆使して作った図を、論文投稿用の高解像度（300dpiや600dpi）のtiffファイルとして保存する方法のメモ。試したのは、Windows 10。

①レジストリエディタの起動（Windowsキー → 「regedit」） ②HKEY　→　CURRENT USER　→　Software　→　Microsoft　→　Office　→　数字　→　Powerpoint　→　options ③メニューから「編集」 → 「新規」 → 「DWORD（32ビット)値」 ④新規追加された項目の名前を「ExportBitmapResolution」変更。ダブルクリック。 ⑥「10進法」値を300や600と入力する。 ⑦これでエディタを閉じると、PowerPointで300dpi（600dpi）で画像を出力する設定に変更できた。

■参照元 【完全保存版】パワーポイントで画像を300dpi化する方法: Windows and Mac | EUS channel
