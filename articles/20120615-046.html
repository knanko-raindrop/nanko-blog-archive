グーグルマップでの分布図作成方法

2012年06月15日 10:05:00勉強：GIS

記事は投稿当時の情報を保存したものです。現在の情報とは異なる可能性があります。

■ソース グーグルマップ google map を利用した簡単分布図作成

■概要 KMLファイルを作成し，それをGoogleMapにインポートすれば分布図が作成される． 意外と簡単であった．便利なサービスだなあ．

■手順 1) Excelで緯度経度情報を持った表を作成する 　1行目　左から順に 　Latitude　Longitude　Name　Description　Icon

  • 　　・Description（吹き出し内の表示内容）
  • 　　・Icon（アイコン番号）

　　　アイコン番号とアイコンの対応表は こちら

　2行目以降にデータを入力

2) Excelファイルをkmlファイルに変換 　下記リンク先のConverterを利用． 　Excel To KML

　ファイルを選択 → View on Google Earth で作成

3) グーグルマップのマイマップにkmlファイルをインポート
