# 南光一樹｜ブログアーカイブ

JUGEM のエクスポート `jugem0.txt` から生成する、2010年9月17日〜2021年2月2日の全74記事の静的アーカイブです。更新を終了した過去の個人ブログとして掲載します。

## 構成

- `index.html`：全記事を新しい順に掲載。年別のページ内リンクで閲覧できます。
- `articles/`：74記事の個別HTML。投稿日・カテゴリ・一覧へのリンク・前後の記事へのリンクを含みます。
- `styles.css`：白背景の共通スタイル。スマートフォン、キーボード操作、印刷に対応します。
- `scripts/generate.py`：元データからHTMLと公開前確認レポートを生成します。
- `scripts/validate.py`：元データと生成物を別の処理で照合し、内部リンクを検証します。
- `scripts/check_external_links.py`：任意で外部URLへのHTTPアクセスを確認します。
- `.nojekyll`：GitHub Pagesでそのまま静的ファイルを配信するためのファイルです。
- `jugem0.txt`：原本。Gitの追跡対象外です。別途バックアップしてください。
- `.local-reports/`：公開前確認候補・検証結果。Gitの追跡対象外です。公開しないでください。

閲覧にJavaScript、CMS、外部ライブラリ、外部フォントは必要ありません。

## 公開前の最終調整方針

- サイト名を「南光一樹｜ブログアーカイブ」に統一し、トップと全74記事のページタイトル・ヘッダー・フッターに反映します。記事そのもののタイトルは原文を保持します。
- トップに2010～2021年の記事を保存した更新終了済みアーカイブであることを明記します。
- トップと全74記事に、投稿当時の情報であり現在の情報とは異なる可能性がある旨を、本文の外の注記として表示します。
- 空行で明確に区切られた本文を段落にし、行頭の「・」「●」「- 」で始まる行が2行以上連続する場合だけ箇条書きとして整えます。元の記号・文字・改行は保持します。単独の記号行、番号付きの手順、文中につながった箇条書きなど、構造を確定できない箇所は推測で分割・補完しません。
- 明記されたURL以外のリンクは新設しません。エクスポートで失われたリンクは復元しません。
- 生成スクリプトから全74記事を再生成し、本文全文の文字列一致とリンクの整合性を検証します。Commit・Push・公開設定は行いません。

## 再生成

Python 3.10以降の標準ライブラリだけを使用します。リポジトリ直下に原本 `jugem0.txt` を配置し、次を実行します。

```sh
python scripts/generate.py
python scripts/validate.py
```

生成スクリプトは場所に依存せずリポジトリ直下を基準に動作します。原本は読み取り専用で扱い、変更しません。74記事でない場合、日付・必須項目に問題がある場合、不正なUTF-8や置換文字がある場合は失敗します。個別ファイル名は `YYYYMMDD-元データ順の連番.html` です。同日の記事も区別できます。原本の順序を変えるとファイル名が変わるため、原本はそのまま保管してください。

記事HTMLとトップページは再生成で上書きされます。修正は生成スクリプトやCSSに加えてください。想定外のHTMLが `articles/` にある場合は自動削除せず停止します。

## 内容の扱い

原本はUTF-8のテキスト形式です。タイトル・カテゴリ・本文のHTMLエンティティを1回復元し、HTMLとして安全にエスケープします。日本語、全角スペース、本文内の改行、投稿日（秒まで）を保持します。記事区切り前後の空行は除去します。タイムゾーンは元データにないため、推測して付加しません。

元データに画像やHTMLタグはありません。画像は追加・移行しません。本文に明記された `http://` / `https://` のURLだけをリンク化し、文字列は変えません。「ここ」「参考」やサイト名だけで参照URLが失われている箇所には、推測したURLや説明を追加しません。元の記事にない内容は本文に追加しません。サイトの案内とナビゲーションは本文の外に配置しています。

## 確認とローカル閲覧

`validate.py` は全74記事についてタイトル・日時・カテゴリ・本文全文の一致、一覧の並び順、年別アンカー、前後のリンク、CSSを含む内部リンクの実在、相対パス、HTMLの入れ子を検証します。結果と原本のSHA-256は `.local-reports/validation.json` に保存します。外部URLの一覧も記録しますが、外部サイトの到達性はこの検証の対象外です。外部リンク先の変更・閉鎖や、URLが原本に存在しない参照は修復しません。

必要に応じて `python scripts/check_external_links.py` を実行すると、外部URL10件のHTTPステータス・リダイレクト先・接続エラーを `.local-reports/external-links.json` に保存します。ネットワーク接続が必要です。403などのアクセス制限や一時的な接続エラーはリンク切れと断定せず、ブラウザで確認してください。結果にかかわらず元のURLは保持します。

`index.html` を直接開くか、次の簡易サーバーで閲覧できます。

```sh
python -m http.server 8000
```

`http://localhost:8000/` を開きます。全リンクを相対パスにしているため、GitHub Pagesの `https://ユーザー名.github.io/リポジトリ名/` でも動作します。

公開前には `.local-reports/publication-review.md` を確認してください。生活・家族・健康、所属・職場・会議、人事、研究上のやり取り、連絡先などに関するキーワードから本文の候補箇所を抽出しています。候補は問題を断定するものではありません。共著者名などの第三者情報も含め、全記事を人の目で確認してください。原文の削除・匿名化は自動では行いません。

## 運用とGitHub Pages

この実装ではCommit、Push、公開設定を行っていません。公開する場合は、上記の確認後に別途GitHub Pagesの公開元を設定してください。リポジトリ直下を公開元にできる構成です。生成にPythonは必要ですが、GitHub Pagesで配信するときのビルド処理は不要です。

`jugem0.txt` と `.local-reports/` は `.gitignore` により除外しています。`git add -f` で追加しないでください。GitHub Pages以外へ手動アップロードするときも、原本とローカルレポートを含めず、`index.html`、`articles/`、`styles.css`、`.nojekyll` のみを配信してください。原本はGitに含まれないため、別の環境で再生成するには安全に保管した原本を再配置する必要があります。

PEDAL公式サイトのファイルは対象外です。このアーカイブは独立したディレクトリで運用します。
